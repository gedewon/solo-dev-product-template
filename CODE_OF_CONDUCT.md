# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and assume good intent. Critique code and ideas, not people. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour makes the project unwelcoming, report it privately to the maintainer, [@gedewon](https://github.com/gedewon), through GitHub. Include links to the comments or threads involved. Reports are kept confidential.

The maintainer may edit or remove comments, close threads, or block anyone who breaks this code of conduct.
